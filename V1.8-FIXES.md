# V1.8 Saved Time Cards, CSV Export, Automatic Pay-Period Rollover

Added:
- Save the current 14-day pay period as a permanent time-card snapshot.
- Saved Time Cards history screen.
- Export each saved time card as a real CSV file on Android/iOS.
- Browser CSV download fallback for the web build.
- CSV includes each entry, straight/OT hours, pay breakdown, notes, and totals.
- Completed pay periods automatically archive when the app opens or refreshes.
- After archival, the active pay period advances forward by 14 days automatically.
- If several old periods have elapsed, the app advances through all of them until
  today's date is inside the active pay period.
- Automatic rollover waits if a clock session from the ending period is still active,
  then rolls after clock-out so the final shift is included.
- Manually saving the same pay period again updates that period's saved snapshot rather
  than creating duplicates.

New SDK 57 dependencies:
- expo-file-system ~57.0.6
- expo-sharing ~57.0.15

Existing entry, settings, appearance, and active-clock storage keys are preserved.
