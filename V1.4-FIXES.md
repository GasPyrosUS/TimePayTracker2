# V1.4 Professional Startup + Dark Mode

Added:
- Professional branded startup/loading screen.
- Subtle startup fade/rise animation.
- Short minimum startup presentation so the first launch does not flash abruptly.
- Light, Dark, and System appearance options.
- System mode follows the phone's current light/dark appearance.
- Appearance choice persists between app launches.
- Dark-mode colors are applied across:
  - Dashboard
  - Time Clock
  - Manual Time Entry
  - Pay Period
  - Settings
  - Cards, inputs, borders, navigation, and status bar
- Expo `userInterfaceStyle` changed to `automatic`.

Preserved:
- Existing time entries.
- Existing hourly rate and overtime multiplier.
- Existing pay-period dates.
- Dashboard synchronization fixes.
- Current overtime rules.

Storage note:
- Existing entry/settings keys remain unchanged.
- Appearance is stored separately under a new key, so this upgrade does not
  reset timekeeping data.
