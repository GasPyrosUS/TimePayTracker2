# V1.5 Editable Entries + Persistent Clock-In

Added:
- Saved time entries can now be edited.
- Tap any Recent Time entry on the Dashboard to edit it.
- Pay Period now contains a Saved Entries section; tap an entry to edit.
- Edit date, clock-in time, clock-out time, break minutes, and notes.
- Editing recalculates straight time, overtime, total hours, and gross pay.
- Saved entries can also be deleted from the Edit Time Entry screen.

Clock-in fix:
- Clock-in is now written to AsyncStorage immediately when CLOCK IN is pressed.
- Leaving the Time Clock screen no longer loses the clock-in time.
- Closing/reopening the app also preserves the active clock-in.
- Returning to Time Clock restores the saved clock-in time and break selection.
- CLOCK OUT converts the persistent clock session into a normal saved entry and
  clears the active clock state.
- The Dashboard now shows `CLOCKED IN • HH:MM` only when a real active clock
  session exists.

Preserved:
- All V1.4 appearance/dark-mode settings.
- Existing entries and pay settings.
- Existing pay-period controls.
- Dashboard gross-pay synchronization.
