# V1.2 Dashboard Sync Fix

Fixes:
- Recent Time updates immediately when a time entry is saved.
- Estimated Gross Pay updates immediately when a time entry is saved.
- Straight Time / Overtime / Total Hours cards update immediately.
- Settings changes (hourly rate, OT multiplier, pay-period start) now notify
  the Dashboard immediately.
- Dashboard still refreshes whenever it regains focus.
- Pull-to-refresh was added as a manual fallback.
- Estimated Gross Pay now uses only entries inside the configured current
  14-day pay period.
- Recent Time still displays the latest entries regardless of pay-period date.

Existing V1.1 entries are preserved because this build intentionally continues
to use the same AsyncStorage keys.
