# V1.8.2 Android Navigation Bar

Changed:
- The Android system navigation bar is hidden while Time & Pay Tracker is open.
- The setting is applied at the root Expo Router Stack, so it covers all app
  screens consistently.
- No additional Expo/native dependency was added.

Android behavior:
- The system navigation bar can still temporarily appear if the user performs
  the Android system gesture used to reveal system controls.
- On devices using gesture navigation, Android may show its gesture indicator
  according to the device/OS behavior.

Preserved:
- Saved time cards and CSV export.
- Automatic pay-period rollover.
- Persistent clock-in.
- Editable time entries.
- Light/Dark/System appearance.
- APK/EAS configuration and dependency pins.
