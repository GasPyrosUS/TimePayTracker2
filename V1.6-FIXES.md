# V1.6 Standard Time / AM-PM

Changed:
- All user-facing work times now display in 12-hour standard time with AM/PM.
- Examples:
  - 07:00 -> 7:00 AM
  - 15:00 -> 3:00 PM
  - 18:30 -> 6:30 PM
- Dashboard active clock time uses AM/PM.
- Dashboard Recent Time uses AM/PM.
- Time Clock uses AM/PM.
- Clock-out confirmation uses AM/PM.
- Pay Period Saved Entries use AM/PM.
- Add/Edit Time Entry fields now accept standard time such as:
  - 7:00 AM
  - 3:00 PM
  - 3:30PM
- Existing 24-hour input such as 15:00 is still accepted for compatibility.

Important:
- Times continue to be stored internally in 24-hour HH:MM format.
- This preserves the existing overtime calculator and avoids changing payroll math.
- Existing saved entries require no migration.
