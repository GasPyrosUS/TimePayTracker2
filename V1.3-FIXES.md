# V1.3 Pay Period Controls

Added:
- Editable pay period start date in Settings.
- Automatically calculated 14-day pay period end date.
- Previous 14 Days and Next 14 Days buttons.
- Exact selected pay-period range shown before saving.
- Date validation before settings can be saved.
- Dashboard now displays exact start and end dates.
- Pay Period screen now displays exact start and end dates.
- Changing the pay-period start immediately recalculates the Dashboard after save.

Business rule preserved:
- Every pay period remains exactly 14 calendar days.
- The end date is therefore start date + 13 days.
