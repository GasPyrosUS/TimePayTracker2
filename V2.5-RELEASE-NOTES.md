# Version 2.5.0

- Added a persistent home-page slider for optional 8-hour weekday straight time.
- When enabled, every Monday–Friday date in the configured 14-day pay period
  contributes 8 straight hours and the corresponding private straight-time pay.
- While enabled, manual, clocked, scanned, and Team Hours entries contribute only
  qualifying overtime hours and overtime pay; their straight-time portions are not
  added again. Turning the slider off restores the original calculation unchanged.
- Dashboard, Add/Edit preview, Pay Period daily breakdown, saved time cards, automatic
  rollover, gross-pay totals, and CSV exports all use the same mode consistently.
- CSV exports include explicit weekday-base rows so detailed rows reconcile with the
  saved straight-hour and gross-pay totals.
- The setting is private and account-scoped. Team Hours continues sharing only the
  existing pay-free public work-hour projection.

Android versionCode: 11. No dependency changes from 2.4.1.
