# 2.2.0 — Type or choose clock times

- Add/Edit Time Entry now supports typing AND the existing dropdown list for clock-in/out.
- Accepts 7:30 AM, 3:45PM and 24-hour values such as 15:45; formats as AM/PM on leaving the field.
- Typed minutes are preserved exactly, including times not in the five-minute dropdown increments.
- Invalid/partial inputs show inline guidance, hide the calculation preview and prevent saving.
- Saves normalized HH:MM using the existing parser, storage, calculator and team-sync path.
- Work date, breaks, saved cards, pay rules and delete confirmation are unchanged.
- No additional packages or Firebase rule changes. Version 2.2.0; Android versionCode 6.
