# Version 2.4.0

- Moved Dashboard, Time, Pay Period, and Settings navigation directly below the
  Dashboard header, with responsive light/dark styling and preserved active state.
- Added dependency-free scale/opacity press feedback to active buttons throughout
  the app and a success-only Settings applied alert plus inline confirmation.
- Added weekday names to every Add/Edit Time Entry work-date choice while retaining
  the Today marker and the configured pay-period date list.
- Added multi-select Team Hours import with a review step, duplicate detection, and
  explicit pay-free local projection. Imported shifts are recalculated with the
  current user's private overtime and pay settings.
- Changed Dashboard pay-period progress to actual Day 1–14 progress with the
  corresponding weekday. Values clamp safely and continue through automatic rollover.
- Preserved Expo SDK 57, EAS/APK, GitHub Pages, saved cards/CSV, dark mode, clock,
  editing/deletion, AM/PM input/display, Firebase sharing, and scan scaffolding.

Team Hours import requires a configured Firebase project, a signed-in user, and an
active team membership. It imports only rows the existing Team Hours service can
already display. Timesheet photo scanning remains marked Coming Soon and still needs
the documented secure OCR backend before it can be enabled.

Android versionCode: 9. Expo SDK 57 patch dependencies were aligned with Expo's
current compatibility recommendations; no new dependency families were added.
