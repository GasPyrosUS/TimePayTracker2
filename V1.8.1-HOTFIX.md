# V1.8.1 Time Card Save Hotfix

Fixed:
- `Property 'saveTimeCard' doesn't exist` when pressing SAVE TIME CARD.
- The V1.8 function was accidentally declared inside the `useFocusEffect`
  callback and was therefore outside the render scope.
- `saveTimeCard()` now exists directly inside the Period component where the
  SAVE TIME CARD button can access it.
- Added a Saving state to prevent duplicate taps while a card is being stored.
- After saving, the confirmation can jump directly to Saved Time Cards.

Preserved:
- Saved time-card storage.
- CSV export.
- Automatic 14-day pay-period rollover.
- Existing time entries and settings.
- Persistent clock-in.
- Editable entries.
- Light/Dark/System appearance.
- APK/EAS configuration and SDK 57 dependency pins.
